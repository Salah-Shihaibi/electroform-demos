# Electroform demos

Two narrated, animated tours of the Holdson Electroform operator panel:

- **The main features**, about 4 minutes
- **The full walkthrough**, about 15 minutes

Open the site and press play. Add `#overview` or `#walkthrough` to the address to open one directly.

`index.html` is a single self-contained page: screenshots and voice-over are embedded, so it works from any static host or straight from disk. It is built from the `demo/` folder of the Electroform repository by `demo/tools/bundle.py`.
